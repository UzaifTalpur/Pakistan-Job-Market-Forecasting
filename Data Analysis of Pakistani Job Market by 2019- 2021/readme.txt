🚩 Project Overview
This project performs an end-to-end Data Science analysis on a dataset of 6,680 job postings in Pakistan, spanning from December 2019 to March 2021. The goal is to identify hiring trends, geographic hotspots, and required skill sets, and to provide a 6-month market forecast using Machine Learning.

📊 Key Findings & Insights
Industry Leaders: IT Jobs represent the largest sector (21%), followed by Customer Service and Sales.

Top Cities: Karachi leads the market with 34% of job postings, followed by Lahore (27%) and Islamabad.

Experience Level: The market is very accessible for fresh talent; over 40% of jobs target candidates with 0–2 years of experience.

Core Skills: There is a high demand for PHP, SQL, JavaScript, and WordPress. Emerging trends show a rise in Python and Data Science requirements.

Growth Forecast: The analysis predicts a steady recovery and growth, forecasting an increase to ~868 jobs per month by late 2021
#Technical Implementation
The project is built using the following Python ecosystem:

Data Manipulation: Pandas, NumPy

Visualization: Matplotlib, Seaborn

Machine Learning: * Classification: Random Forest (used to categorize jobs based on descriptions).

Clustering: K-Means (used to group similar job types).

Forecasting: Linear Regression (used for monthly trend prediction).

Report Generation: ReportLab (used to automatically generate the 12-page PDF report).

📁 Folder Structure
Job Market Analysis.ipynb: The main Jupyter Notebook containing all Python code.

Pakistan Available Job Dec 19 - Mar-21.csv: The raw dataset used for analysis.

Pakistan_Job_Market_Report.pdf: The final professional report generated by the code.

figures/: A folder containing 14 automated charts and graphs.
